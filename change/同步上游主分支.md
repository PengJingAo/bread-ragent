# 同步上游主分支

## 变更原因

个人仓库的 `main` 分支相对上游存在 11 个本地独有提交和 26 个上游独有提交。本次通过合并方式同步上游，保留已有提交哈希和本地功能，避免变基及强制推送带来的历史重写风险。

## 冲突处理

- 采用上游新版检索包结构和检索预算接口，将关键词索引回灌任务迁移到 `rag.core.keyword`。
- 保留关键词检索的高置信 KB 意图门槛，并移除已被新版预算模型替代的旧 `mode`、`topKMultiplier` 配置。
- 同时保留回答最大 Token 数、上下文元数据富化、关键词索引回灌和上游新增的存储、图谱及审计配置。
- 默认关闭关键词通道，使其与默认的 `rag.keyword.type=none` 保持一致；启用 ES 时需要同时打开关键词通道。
- 合并 Maven 依赖和 Claude 本地权限配置，保留双方新增项。

## 验证结果

- Maven 多模块编译通过。
- 检索配置测试及 MCP Server 测试通过。
- 前端生产构建通过。
- 完整 Spring 上下文测试需要本地 Redis 等外部服务；Windows 下另有一个上游模板换行符断言差异。
- 上游当前 ESLint 8 与 `eslint-plugin-react-refresh` 推荐配置存在兼容问题，未在本次同步中扩大范围修复。
